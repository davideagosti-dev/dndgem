# DnDGem 0.1.0-alpha.3 — Cross-Framework Alpha Recovery

**Status:** **PUBLISHED** — npm `@alpha` → `0.1.0-alpha.3` (DND-FX.6 Final Closure validated).

**Brand:** DnDGem by DA62

**Release date:** 2026-08-18

**Category:** Content-Aware Adaptive Layout Engine — Framework Expansion (recovery)

---

## Recovery reason

`0.1.0-alpha.2` was published, but the first bootstrap of `@dndgem/vue`, `@dndgem/angular`, and `@dndgem/svelte` used direct `npm publish` from package directories. That bypassed pnpm workspace protocol rewriting, leaving published dependency metadata as `@dndgem/core: workspace:*` and `@dndgem/dom: workspace:*`. External consumers fail with `EUNSUPPORTEDPROTOCOL`.

`0.1.0-alpha.3` republishes all six public packages lockstep through the repository-approved GitHub Actions / pnpm / OIDC Trusted Publishing path with correct resolved semver dependencies in tarball metadata. **No runtime API changes.** Direct `npm publish` was **not** used for alpha.3.

`0.1.0-alpha.2` is **superseded** for external installs. Do not use Vue/Angular/Svelte exact `0.1.0-alpha.2` installs from npm.

## Install

```bash
# React (pulls @dndgem/dom + @dndgem/core)
npm install @dndgem/react@alpha

# Vue
npm install @dndgem/vue@alpha

# Angular
npm install @dndgem/angular@alpha

# Svelte
npm install @dndgem/svelte@alpha

# Vanilla / DOM
npm install @dndgem/dom@alpha
npm install @dndgem/core@alpha
```

Official version: **`0.1.0-alpha.3`**. Always use dist-tag **`alpha`**.

Exact version installs also work: `@dndgem/*@0.1.0-alpha.3`.

### Meta-framework environments (not npm packages)

| Environment | Install adapter                    |
| ----------- | ---------------------------------- |
| Next.js     | `npm install @dndgem/react@alpha`  |
| Nuxt        | `npm install @dndgem/vue@alpha`    |
| SvelteKit   | `npm install @dndgem/svelte@alpha` |

There is no `@dndgem/next`, `@dndgem/nuxt`, or `@dndgem/sveltekit`.

### Dist-tags (actual after publication)

| Dist-tag | Core / DOM / React                          | Vue / Angular / Svelte                                        |
| -------- | ------------------------------------------- | ------------------------------------------------------------- |
| `alpha`  | `0.1.0-alpha.3` (official Alpha channel)    | `0.1.0-alpha.3` (official Alpha channel)                      |
| `latest` | `0.1.0-alpha.0` (historical; **unchanged**) | `0.1.0-alpha.2` (npm first-package assignment; **unchanged**) |

`latest` asymmetry is a **non-blocking Alpha-era exception**. This release did **not** promote `0.1.0-alpha.3` to `latest`. Do not treat bare `npm install @dndgem/*` / `latest` as the supported Alpha path.
