## What this Alpha adds

Cross-Framework Alpha on top of Phase 3 Auto-Layout (`0.1.0-alpha.1`):

| Area           | Capability                                                                                |
| -------------- | ----------------------------------------------------------------------------------------- |
| Vue            | First public `@dndgem/vue` adapter (`vue@^3.5` peer)                                      |
| Angular        | First public `@dndgem/angular` adapter (`@angular/core@^20 \|\| ^21 \|\| ^22` peer)       |
| Svelte         | First public `@dndgem/svelte` adapter (`svelte@^5` peer; client/server export boundary)   |
| Next.js        | Validated with `@dndgem/react` (App Router, `'use client'` integration root)              |
| Nuxt           | Validated with `@dndgem/vue`                                                              |
| SvelteKit      | Validated with `@dndgem/svelte` (SSR import/build shell safe; client session after mount) |
| Core/DOM/React | Version-aligned with new adapters on the shared `@alpha` channel                          |

All six public packages share **`0.1.0-alpha.2`** via Changesets fixed group.

## Install

```bash
# React (pulls @dndgem/dom + @dndgem/core)
npm install @dndgem/react@alpha

# Vue
npm install @dndgem/vue@alpha

# Angular
npm install @dndgem/angular@alpha

# Svelte
npm install @dndgem/svelte@alpha

# Vanilla / DOM
npm install @dndgem/dom@alpha
npm install @dndgem/core@alpha
```

Official version: **`0.1.0-alpha.2`**. Always use dist-tag **`alpha`**.

Exact version installs also work: `@dndgem/*@0.1.0-alpha.2`.

### Meta-framework environments (not npm packages)

| Environment | Install adapter                    |
| ----------- | ---------------------------------- |
| Next.js     | `npm install @dndgem/react@alpha`  |
| Nuxt        | `npm install @dndgem/vue@alpha`    |
| SvelteKit   | `npm install @dndgem/svelte@alpha` |

There is no `@dndgem/next`, `@dndgem/nuxt`, or `@dndgem/sveltekit`.

### Dist-tags (expected after publication)

| Dist-tag | Expected                                                |
| -------- | ------------------------------------------------------- |
| `alpha`  | `0.1.0-alpha.2` (official Alpha channel)                |
| `latest` | `0.1.0-alpha.0` (**unchanged** — not the Alpha channel) |

Do not treat bare `npm install @dndgem/*` / `latest` as the supported Alpha path.

## SSR / hydration boundary

```text
MODULE IMPORT SAFE  ≠  SERVER-SIDE DNDGEM SESSION
```

- **Next.js / Nuxt / SvelteKit:** production build, server import/render shell, client hydration, and one client session after mount are validated.
- **Svelte:** server compile / import safety included; client session after mount.
- **Angular Universal:** not validated.

Do not claim server-side layout solving.

## Upgrade from 0.1.0-alpha.1

- Install all adapters with `@alpha` — six packages align on `0.1.0-alpha.2`.
- Vue, Angular, and Svelte move from workspace-only to npm for the first time.
- Core/DOM/React APIs unchanged in intent; version bump is lockstep alignment only unless your app pinned exact alpha.1 versions (reinstall `@alpha`).

## Known limitations

- 0.x Alpha — API may break between prereleases
- Auto-Layout remains **opt-in** (default off)
- Desktop Chromium / Firefox / WebKit validated; **mobile/touch not validated**
- Keyboard drag deferred
- Screen-reader drag UX deferred
- Angular Universal not validated
- AI deferred (Phase 4)
- Repository remains **PRIVATE** (npm packages public)
