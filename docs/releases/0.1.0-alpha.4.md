# DnDGem 0.1.0-alpha.4 — Phase 4 Layout Intelligence (Public Surface)

**Status:** **PREPARED — NOT PUBLISHED** — repository/source version `0.1.0-alpha.4`; npm dist-tag `@alpha` remains `0.1.0-alpha.3` until the authorized publish gate.

**Brand:** DnDGem by DA62

**Category:** Content-Aware Adaptive Layout Engine — Phase 4 public packaging

---

## What this Alpha adds

Phase 4 public packaging of accepted DND-4.2 / DND-4.3 surfaces on top of the Cross-Framework Alpha foundation (`0.1.0-alpha.3`):

| Area    | Capability                                                                                                                                    |
| ------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| Core    | Optional `automaticItemOrder` on `AutoLayoutProposalInput` — advisory automatic-item processing order (DND-4.2). Omitted → unchanged default. |
| DOM     | Optional session `planner` / `onPlannerEvent` and explicit `session.replan(): Promise<void>` (DND-4.3). No planner configured → unchanged.    |
| React   | Matching optional `planner` / `onPlannerEvent` / `replan()` parity over the DOM session                                                       |
| Vue     | Same optional planner / `replan()` parity                                                                                                     |
| Angular | Same optional planner / `replan()` parity                                                                                                     |
| Svelte  | Same optional planner / `replan()` parity                                                                                                     |

Architectural principle (binding):

```text
Intelligence proposes.
Deterministic DnDGem validates and resolves.
```

`solveLayout` / `evaluateLayout` remain the only validity, scoring, and resolution authority. Planning proposals are **UNTRUSTED** until validated/normalized. Fail closed to deterministic fallback.

All six public packages share **`0.1.0-alpha.4`** via the Changesets fixed group.

---

## What this Alpha does NOT include

- **No** publication of `@dndgem/intelligence` or `@dndgem/intelligence-openai` (private workspace packages only)
- **No** default model inference or OpenAI / LLM runtime dependency in public packages
- **No** planner invocation in hot paths (pointermove / rAF / ResizeObserver / every solve)
- **No** automatic DOM / focus / tab / ARIA reorder by intelligence
- Model assistance remains **DEFERRED UNTIL NEW EVIDENCE** (DND-4.4 disposition)

## Install (after publication)

Until npm publish completes, `@alpha` still resolves to **`0.1.0-alpha.3`**. After publication:

```bash
# React (pulls @dndgem/dom + @dndgem/core)
npm install @dndgem/react@alpha

# Vue
npm install @dndgem/vue@alpha

# Angular
npm install @dndgem/angular@alpha

# Svelte
npm install @dndgem/svelte@alpha

# Vanilla / DOM
npm install @dndgem/dom@alpha
npm install @dndgem/core@alpha
```

Prepared source version: **`0.1.0-alpha.4`**. Always use dist-tag **`alpha`** after publish. Exact installs: `@dndgem/*@0.1.0-alpha.4`.

## Upgrade from 0.1.0-alpha.3

- Reinstall with `@alpha` after publish — six packages align on `0.1.0-alpha.4`.
- Opt into `automaticItemOrder` only when you want advisory automatic-item ordering.
- Opt into `planner` / `replan()` only when you configure a planner; defaults unchanged.
- No migration required for existing Auto-Layout / drag / adapter consumers that omit the new options.

---

## Known limitations

- 0.x Alpha — API may break between prereleases
- Auto-Layout remains **opt-in** (default off)
- Planner remains **opt-in** (default off / no planner)
- Desktop Chromium / Firefox / WebKit validated; **mobile/touch not validated**
- Keyboard drag deferred
- Screen-reader drag UX deferred
- Angular Universal not validated
- Model assistance deferred (DND-4.4)
- Public intelligence packages are not published
