Support

DnDGem is open source on GitHub. Use the contacts below for Alpha feedback and security reports, or open an issue in the public repository.

Product / Alpha feedback

Email support@dndgem.dev for integration questions, Alpha feedback, and non-security bugs.

Security

Report vulnerabilities privately to security@dndgem.dev. Do not use the product support inbox for undisclosed security issues.
